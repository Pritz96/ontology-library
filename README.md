# Ontology Library

A collection of ontologies/vocabs (in turtle format) all in one place.

## DCAT3
[dcat3.ttl](https://www.w3.org/ns/dcat3.ttl)

## Dublin Core Terms
[dublin_core_terms.ttl](https://www.dublincore.org/specifications/dublin-core/dcmi-terms/dublin_core_terms.ttl)

## GEOSPARQL (geo.ttl)
[geo.ttl](https://raw.githubusercontent.com/opengeospatial/ogc-geosparql/refs/heads/master/vocabularies/geo.ttl)

## Hydra (Core Vocabulary)
[hydra-core-vocabulary.ttl](https://raw.githubusercontent.com/Pritz96/ontology-library/serialised-ontologies/refs/heads/main/hydra-core-vocabulary.ttl)

## OWL
[owl.ttl](https://www.w3.org/2002/07/owl.ttl)

## RDFS
[rdf-schema.ttl](https://www.w3.org/2000/01/rdf-schema.ttl)

## SDMX Codelists
https://registry.sdmx.org/items/codelist.html

## SKOS (serialised from RDF/XML into turtle)
[skos.ttl](https://raw.githubusercontent.com/Pritz96/ontology-library/serialised-ontologies/refs/heads/main/skos.ttl)

## SOSA Editors Edition (serialised into a single file)
[sosa-editors-edition.ttl](https://raw.githubusercontent.com/Pritz96/ontology-library/serialised-ontologies/refs/heads/main/sosa-editors-edition.ttl)

## SOSA + SSN Editors Edition (serialised into a single file)
[sosa-ssn-editors-edition.ttl](https://raw.githubusercontent.com/Pritz96/ontology-library/serialised-ontologies/refs/heads/main/sosa-ssn-edition.ttl)

## XKOS
[xkos.ttl](https://rdf-vocabulary.ddialliance.org/xkos.ttl)
